# Project status

What exists right now. "Implemented" means present at HEAD with a test that
exercises it.

The crate, the desktop channel, export mode, and the pipe session are
implemented. No recording of the game exists yet, so what the reader reads from
the game itself is untested: its process names, its runtime's layout, and which
of its objects are souls.
